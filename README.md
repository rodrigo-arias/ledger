# Ledger

A personal ledger for couples sharing expenses. Track daily spending in ARS/USD, calculate fair splits, and settle up monthly.

## Features

- **Shared expenses** - Track spending between two people
- **Multi-currency** - ARS/USD with monthly exchange rates
- **Monthly balance** - Who owes what, with carry-over
- **Payment tracking** - Record payments and close months
- **Fixed expenses** - Assign rent, utilities to one person
- **Categories** - Organize with custom emojis
- **Offline-first** - Works without internet

## Tech Stack

- SwiftUI + SwiftData
- iOS 18+ / macOS 15+
